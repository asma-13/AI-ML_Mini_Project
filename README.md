## 🧠 About the Project

This mini project was created as part of the **Artificial Intelligence & Machine Learning** course at **Sukkur IBA University**, under the guidance of **Dr. Mumtaz Ali Kaloi**.

The goal was to perform **Exploratory Data Analysis (EDA)** on a dataset containing individuals' **height, weight, shoe size, and gender**. The focus was on applying descriptive statistics to explore data patterns and draw useful interpretations.

---

## 🔢 Dataset Features

- `Height (cm)`
- `Weight (kg)`
- `Shoe Size`
- `Gender`

---

## ✅ What I Did

- Cleaned and structured the dataset using **pandas**
- Created a **DataFrame** for easy manipulation
- Performed descriptive statistical analysis:
  - Mean
  - Mode
  - Standard Deviation
- Interpreted the findings to gain initial insights

This project helped me better understand the importance of EDA as a foundational step in any machine learning workflow.
